# AI・自動化機能設計書

Outlookにはない、AIおよび自動化に特化した機能についての設計書

---

## 1. AIメール生成

### 概要
Langchain + OpenAI GPTを用いて、指示に基づきメール本文を自動生成する

### 機能詳細

| 項目 | 説明 |
|------|------|
| チャット形式 | 対話的に要件を伝えて生成 |
| トーン選択 | フォーマル/カジュアル/丁寧から選択 |
| 相手タイプ指定 | 上司/同僚/顧客/取引先に応じた文体 |
| 複数ターン対応 | 修正依頼を重ねて調整可能 |

### 使用例
```
ユーザー: 「明日の会議をリスケしたいメールを書いて」
AI: 件名と本文を自動生成
```

### 実装箇所
- バックエンド: `backend/routers/ai_generate.py` (`POST /ai/chat`)
- サービス: `backend/services/langchain_service.py`

## 2. AI文体改善提案

### 概要
作成中のメール本文を解析し、より丁寧・適切な表現を提案する

### 機能詳細

| 項目 | 説明 |
|------|------|
| リアルタイム解析 | 本文入力中に提案を表示 |
| 改善候補表示 | 複数の代替表現を提示 |

### 実装箇所
- フロントエンド: `frontend/app/components/PolitenessSuggestions.tsx`
- バックエンド: `backend/routers/mail.py` (`POST /mail/suggest-polite`)

## 3. AI宛先フィルタリング

### 概要
自然言語の条件指定でメーリングリストから宛先を絞り込む

### 機能詳細

| 項目 | 説明 |
|------|------|
| 自然言語入力 | 「営業部で課長以上」など日本語で指定 |
| LLM条件抽出 | Langchainが条件をパースしフィルタ実行 |
| 結果プレビュー | 絞り込み結果を確認後に適用 |

### 使用例
```
入力: 「東京勤務で30代の社員」
結果: 該当する宛先のみ抽出
```

### 実装箇所
- フロントエンド: `frontend/app/components/AIRecipientFilter.tsx`
- バックエンド: `backend/routers/recipients.py` (`POST /recipients/lists/{id}/filter`)

---

## 4. AI宛先検索エージェント

### 概要
チャット形式で自然言語により宛先を検索・選択する

### 機能詳細

| 項目 | 説明 |
|------|------|
| 対話型検索 | 「営業部の人に送りたい」など自然な会話で検索 |
| 除外指定 | 「田中さん以外」「チーフを除く」などの除外条件 |
| 役職・部署検索 | 役職や部署を指定して一括選択 |
| 構造化出力 | JSON形式でメールアドレスを確実に取得 |

### 使用例
```
ユーザー: 「営業部の人」
AI: 営業部の2名を宛先に追加します。
    [田中太郎 <tanaka@example.com>]
    [鈴木花子 <suzuki@example.com>]
```

### 実装箇所
- バックエンド: `backend/routers/recipients.py` (`POST /recipients/ai-agent/chat`)

## 5. Entra ID宛先検証

### 概要
送信前に宛先がEntra ID（Azure AD）に登録済みか検証し、警告を表示する

### 機能詳細

| 項目 | 説明 |
|------|------|
| 自動検証 | 送信ボタン押下時に全宛先をチェック |
| 未登録警告 | Entra IDに存在しない宛先を警告 |
| 社外判定 | ログインユーザーと異なるドメインを検出 |
| 確認ダイアログ | 警告対象がある場合、確認を求める |

### 実装箇所
- フロントエンド: `frontend/app/components/RecipientValidationDialog.tsx`
- バックエンド: `backend/services/entra_validation_service.py`

---

## 9. 非同期ジョブ処理

### 概要
時間のかかる処理をバックグラウンドで実行し、完了を通知する

### 機能詳細

| 項目 | 説明 |
|------|------|
| ジョブキュー | メール送信、検証処理を非同期実行 |
