# 標準メール機能設計書

Outlookメールと同等の基本機能についての設計書

---

## 1. メール作成・送信

### 概要
宛先指定、件名・本文入力、添付ファイル追加を行いメールを送信する

### 機能詳細

| 項目 | 説明 |
|------|------|
| To/Cc/Bcc | 複数宛先指定可能、チップ形式で表示 |
| 件名 | テキスト入力 |
| 本文 | リッチテキスト対応 |
| 送信 | Microsoft Graph API経由でOutlookから送信 |

### 実装箇所
- フロントエンド: `frontend/app/compose/page.tsx`
- バックエンド: `backend/routers/mail.py` (`POST /mail/send`)

---

## 2. 宛先検索

### 概要
宛先入力時にユーザーを検索し候補を表示する

### 機能詳細

| 項目 | 説明 |
|------|------|
| インクリメンタル検索 | 入力に応じて候補をリアルタイム表示 |
| Entra ID連携 | Azure AD登録ユーザーを検索 |
| ローカルキャッシュ | DBに保存された連絡先を優先検索 |
| ファジー検索 | タイプミスを許容した曖昧検索 |

### 実装箇所
- フロントエンド: `frontend/app/components/RecipientInput.tsx`
- バックエンド: `backend/routers/recipients.py` (`GET /recipients/search/unified`)

---

## 3. 添付ファイル

### 概要
メールにファイルを添付して送信する

### 機能詳細

| 項目 | 説明 |
|------|------|
| アップロード | ドラッグ&ドロップまたはファイル選択 |
| 一時保存 | セッション単位で一時保存 |
| 削除 | 送信前に添付解除可能 |

### 実装箇所
- バックエンド: `backend/routers/attachments.py`
- モデル: `backend/models/temp_attachment.py`

---

## 4. 署名管理

### 概要
メール末尾に挿入する署名を管理する

### 機能詳細

| 項目 | 説明 |
|------|------|
| 複数署名登録 | 用途別に複数の署名を保存 |
| デフォルト設定 | 自動挿入する署名を指定 |
| 手動挿入 | メール作成時に任意の署名を選択 |

### 実装箇所
- フロントエンド: `frontend/app/signatures/page.tsx`
- バックエンド: `backend/routers/signatures.py`

---

## 5. 送信履歴

### 概要
過去に送信したメールの履歴を確認する

### 機能詳細

| 項目 | 説明 |
|------|------|
| 履歴一覧 | 送信日時、宛先、件名を一覧表示 |
| ステータス確認 | 送信成功/失敗を確認 |
| 削除 | 履歴からの削除 |

### 実装箇所
- フロントエンド: `frontend/app/history/page.tsx`
- バックエンド: `backend/routers/mail.py` (`GET /mail/logs`)

---

## 6. 認証（Entra ID OAuth2）

### 概要
Microsoft Entra IDによるシングルサインオン

### 機能詳細

| 項目 | 説明 |
|------|------|
| OAuth2認証 | Azure ADと連携したログイン |
| トークン管理 | アクセストークンの自動更新 |
| ユーザー情報取得 | Graph APIからプロフィール取得 |

### 実装箇所
- フロントエンド: `frontend/app/login/page.tsx`
- バックエンド: `backend/routers/auth.py`

---

## 7. メーリングリスト管理

### 概要
宛先グループを作成し一括管理する

### 機能詳細

| 項目 | 説明 |
|------|------|
| リスト作成 | 名前と説明を付けてグループ作成 |
| リスト編集 | 名前・説明の変更 |
| リスト削除 | 不要なリストを削除 |
| メンバー追加 | 手動で個別にメンバーを追加 |
| メンバー編集 | メールアドレス、名前、部署、役職、社員番号を編集 |
| メンバー削除 | リストから個別にメンバーを削除 |
| To/Cc/Bcc振り分け | メンバーごとに宛先種別を設定 |

### 実装箇所
- フロントエンド: `frontend/app/recipients/page.tsx`
- バックエンド: `backend/routers/recipients.py`

---

## 8. メーリングリストのインポート・エクスポート

### 概要
外部ファイルから宛先を一括登録する

### 機能詳細

| 項目 | 説明 |
|------|------|
| CSV/Excelインポート | ファイルから新規リストを作成 |
| 既存リストへの追加 | ファイルから既存リストにメンバーを追加 |
| テンプレートダウンロード | シンプル版（全員To）と振り分け版（To/Cc/Bcc対応） |
| カラム自動認識 | メールアドレス、名前、部署、役職、社員番号を自動判定 |
| 重複チェック | 既存メンバーと重複するアドレスはスキップ |

### 実装箇所
- バックエンド: `backend/routers/recipients.py` (`POST /recipients/upload`, `POST /recipients/lists/{id}/import`)

---

## 9. テンプレート管理

### 概要
定型文をテンプレートとして保存・再利用する

### 機能詳細

| 項目 | 説明 |
|------|------|
| 作成・編集 | 件名と本文をセットで保存 |
| カテゴリ分類 | 用途別に整理 |
| テンプレート適用 | メール作成時に選択して挿入 |

### 実装箇所
- フロントエンド: `frontend/app/templates/page.tsx`
- バックエンド: `backend/routers/templates.py`
